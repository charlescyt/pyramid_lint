# avoid_single_child_in_flex

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
|   Info   |    ✅     |   ❌    |

## Details

**Avoid** using Column or Row with only one child.

```dart title="Bad"
Row(
  children: [
    Placeholder(),
  ],
)
```

```dart title="Good"
Align(
  child: Placeholder(),
)

// or

Center(
  child: Placeholder(),
)
```

## Usage

To enable the `avoid_single_child_in_flex` rule, add `avoid_single_child_in_flex` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      avoid_single_child_in_flex: true
```
