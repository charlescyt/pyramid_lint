# prefer_void_callback

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
|   Info   |    ✅     |   ❌    |

## Details

**PREFER** using the built-in typedef `VoidCallback` instead of declaring a custom one.

```dart title="Bad"
final void Function() cb;
```

```dart title="Good"
final VoidCallback cb;
```

## Usage

To enable the `prefer_void_callback` rule, add `prefer_void_callback` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      prefer_void_callback: true
```
