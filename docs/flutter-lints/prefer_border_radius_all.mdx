# prefer_border_radius_all

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
|   Info   |    ✅     |   ❌    |

## Details

**PREFER** using `BorderRadius.all` instead of `BorderRadius.circular`.

Using `BorderRadius.all` is more efficient than `BorderRadius.circular` because of possible const constructor usage.

```dart title="Bad"
DecoratedBox(
  decoration: BoxDecoration(
    borderRadius: BorderRadius.circular(8),
  ),
)
```

```dart title="Good"
const DecoratedBox(
  decoration: BoxDecoration(
    borderRadius: BorderRadius.all(Radius.circular(8)),
  ),
)
```

## Usage

To enable the `prefer_border_radius_all` rule, add `prefer_border_radius_all` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      prefer_border_radius_all: true
```
