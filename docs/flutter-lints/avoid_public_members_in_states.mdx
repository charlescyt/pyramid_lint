# avoid_public_members_in_states

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
|   Info   |    ❌     |   ❌    |

## Details

**AVOID** declaring public fields and methods in widget state classes.

<Info> Public fields and methods with `@visibleForTesting` annotations are ignored. </Info>

```dart title="Bad"
class _MyWidgetState extends State<MyWidget> {
  int counter = 0;

  void increment() {
    setState(() {
      counter++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return FilledButton(
      onPressed: increment,
      child: Text('$counter'),
    );
  }
}
```

```dart title="Good"
class _MyWidgetState extends State<MyWidget> {
  int _counter = 0;

  void _increment() {
    setState(() {
      _counter++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return FilledButton(
      onPressed: _increment,
      child: Text('$_counter'),
    );
  }
}
```

## Usage

To enable the `avoid_public_members_in_states` rule, add `avoid_public_members_in_states` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      avoid_public_members_in_states: true
```
