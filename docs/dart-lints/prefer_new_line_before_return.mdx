# prefer_new_line_before_return

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
|   Info   |    ✅     |   ❌    |

## Details

**DO** add a new line before the return statement.

```dart title="Bad"
if (...) {
  ...
  return ...;
}
return ...;
```

```dart title="Good"
if (...) {
  ...

  return ...;
}

return ...;
```

## Usage

To enable the `prefer_new_line_before_return` rule, add `prefer_new_line_before_return` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      prefer_new_line_before_return: true
```
