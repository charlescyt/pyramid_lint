# prefer_immediate_return

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
|   Info   |    ✅     |   ❌    |

## Details

**DO** return the result of an expression directly instead of assigning it to a variable and then returning the variable.

```dart title="Bad"
int add(int a, int b) {
  final result = a + b;
  return result;
}
```

```dart title="Good"
int add(int a, int b) {
  return a + b;
}
```

## Usage

To enable the `prefer_immediate_return` rule, add `prefer_immediate_return` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      prefer_immediate_return: true
```
