# avoid_empty_blocks

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
| Warning  |    ❌     |   ❌    |

## Details

**DO** avoid empty blocks as they are usually a sign of missing implementation.

```dart title="Bad"
void doSomething() {}
```

```dart title="Good"
void doSomething() {
  actuallyDoSomething();
}

void doSomething() {
  // TODO: implement doSomething
}
```

## Usage

To enable the `avoid_empty_blocks` rule, add `avoid_empty_blocks` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      avoid_empty_blocks: true
```
