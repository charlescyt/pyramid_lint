# avoid_mutable_global_variables

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
| Warning  |    ❌     |   ❌    |

## Details

**DO** avoid using mutable global variables.

```dart title="Bad"
double pi = 3.14;
```

```dart title="Good"
const double pi = 3.14;
const pi = 3.14;
```

## Usage

To enable the `avoid_mutable_global_variables` rule, add `avoid_mutable_global_variables` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      avoid_mutable_global_variables: true
```
