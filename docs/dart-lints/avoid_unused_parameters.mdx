# avoid_unused_parameters

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
| Warning  |    ❌     |   ✅    |

## Details

**DO** avoid unused parameters.

Unused parameters should be removed to avoid confusion.

```dart title="Bad"
void log(String a, String b) {
  print(a);
}
```

```dart title="Good"
void log(String a) {
  print(a);
}
```

## Usage

To enable the `avoid_unused_parameters` rule, add `avoid_unused_parameters` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      avoid_unused_parameters: true
```

## Options

| Option               | Type           | Description                     | Default Value |
| -------------------- | -------------- | ------------------------------- |:-------------:|
| `ignored_parameters` | `List<String>` | A list of parameters to ignore. |     `[]`      |

To configure the list of ignored parameters, add `ignored_parameters` under `plugins > pyramid_lint > options`:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      avoid_unused_parameters: true
    options:
      avoid_unused_parameters:
        ignored_parameters:
          - ref
```
