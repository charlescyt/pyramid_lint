# unnecessary_nullable_return_type

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
| Warning  |    ✅     |   ❌    |

## Details

**AVOID** declaring functions or methods with a nullable return type when the return value is never null.

```dart title="Bad"
int? sum(int a, int b) {
  return a + b;
}
```

```dart title="Good"
int sum(int a, int b) {
  return a + b;
}
```

## Usage

To enable the `unnecessary_nullable_return_type` rule, add `unnecessary_nullable_return_type` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      unnecessary_nullable_return_type: true
```
