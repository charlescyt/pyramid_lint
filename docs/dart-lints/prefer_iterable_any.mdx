# prefer_iterable_any

| Severity | Quick Fix | Options |
|:--------:|:---------:|:-------:|
|   Info   |    ✅     |   ❌    |

## Details

**DO** use `iterable.any` instead of `iterable.where().isNotEmpty`.

```dart title="Bad"
const numbers = [1, 2, 3];
final hasPositiveNumber = numbers.where((number) => number > 0).isNotEmpty;
```

```dart title="Good"
const numbers = [1, 2, 3];
final hasPositiveNumber = numbers.any((number) => number > 0);
```

## Usage

To enable the `prefer_iterable_any` rule, add `prefer_iterable_any` under `plugins > pyramid_lint > diagnostics` in your `analysis_options.yaml` file:

```yaml
plugins:
  pyramid_lint: <version>
    diagnostics:
      prefer_iterable_any: true
```
